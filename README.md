# 生成AIの界隈の、いちばん新しいやり方

生成AIの界隈で、**使い手の間で** 起きている新しいやり方を拾い、**取り入れ方まで書いて** 定期的に出します。

- 公式の発表や、企業のセミナーは扱いません。作り手・試す人・広める人の間で起きていることを扱います
- 人気の数字だけでは選びません。選び方は [取捨選択の基準](CRITERIA.md) にあり、号を重ねながら直していきます

## 読み方

各号の項目は1項目1ファイルで、ファイルの中が2つの部分に分かれています。

| 部分 | 誰のためか | 中身 |
|---|---|---|
| **人向けの概要** | 人 | 何か、なぜいま話題か、何が良くなるか、手間、気をつけること、対応環境 |
| **生成AI向けの詳細** | AI | 入れ方・使い方・確かめ方・やってはいけないことを、AI がそのまま実行できる細かさで |

AI に渡すときは、そのファイルを丸ごと渡すか（GitHub の「Raw」で開いた URL を渡す、または中身を貼る）、「生成AI向けの詳細」から下を渡してください。

## ラベルの読み方

| ラベル | 意味 |
|---|---|
| 採用 | 取り入れる価値がある。詳細を書いた |
| 様子見 | 良さそうだが決め手が無い。次号以降で見直す |
| 不採用 | 取り上げない。理由を書く |
| 新顔 | 直近ひと月ほどで出てきたもの |
| 定番 | 前からあり、すでに広まっているもの |
| 推測 | 確かめていない見立て。文中でそのつど「推測」と明記する |

## 中身の確かさについて

- 数字は、その号の日付にページに出ていた値です。数え直してはいません
- 各項目の末尾に、その号で読んだ出典を載せています
- 「この号で確かめた」と書いたものだけが、実際に動かして確かめたものです
