# 2026-10-17 号

期間: 直近およそ1か月（2026-09-17〜10-17）。日本語圏と英語圏。

## 今号の結論

1. **AIに画像を「生成」させるのではなく、コードを書かせてブラウザで絵・3D・動画・図にするのが、いちばん大きな流れ。** Three.js（ブラウザで3Dを描くライブラリ）を使う3Dは、その一例
2. **その流れを支えているのが「スキル」（AI に手順やこつを教える、追加の指示書）の共有。** 図・画面・動画を上手に作らせるスキルが、どの AI エージェントにも同じ形で入る
3. **日本の技術者の界隈では、使い方と費用の話が中心。** サブエージェントのモデルの割り当て、コードレビューに案件の知識を足す、など

## 読み方

- **人が読む**: 下の表で気になったものを開き、冒頭の「人向けの概要」だけ読めば足ります
- **AIに渡す**: 項目のファイルの「生成AI向けの詳細」から下を、そのまま AI に渡してください。AI がそれを読んで、入れ方から使い方までを代わりに進めます
- 各項目の「対応環境」の表に、どの AI・どの OS で使えるか、ネットや API キーが要るか、外へ何か送るかを書いています
- よく出る語: リポジトリ（GitHub などでコードや文書を置いておく場所）、スター（GitHub の「いいね」にあたるもの）、API キー（プログラムから AI のサービスを使うときに要る、パスワードのような文字列）、Node.js（JavaScript で書かれたツールを動かすためのソフト）、トークン（AI が読み書きする文章の量を数える単位）
