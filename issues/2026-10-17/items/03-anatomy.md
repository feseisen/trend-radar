# 03 Anatomy（仕組みを、回して分解できる立体図にする）

号: 2026-10-17 ／ 判定: **採用**（新顔。次号で伸び方を見直す） ／ 確かめた日: 2026-10-17

## 人向けの概要

- **何か**: 一行の頼みから、機械や仕組みの **立体のイラスト（斜めから見た図）** を作るスキル。回す・分解する・動かす、ができる。画像ではなく、コード（SVG と WebGL）で描く（[リポジトリ](https://github.com/wheresryan22/anatomy)、MIT）
- **なぜいま話題か**: 2026-10-08 に作られ、10-10 に X で告知。告知の投稿は表示約140万回・保存約1.9万（10-12 時点、[紹介記事](https://cellcog.ai/blog/anatomy-claude-skill/)。この記事を書いた会社はこの道具を配っている側なので、数字はその会社の書いた値）。同じ週末、「Claude がついに画像を作れるようになった」という誤った投稿も広がった（中身はコードで描いた図）
- **現物の数字**（2026-10-17）: 星 6.6k、フォーク 475、イシュー 2。作って9日でフォークが多い
- **取り入れると何が良くなるか**（推測）: 「この仕組みはどう動くのか」を、文章や平面の図より速く伝えられる。例としてリポジトリは「トークンバケット（流量を制限する仕組み）を対話的に説明して」を挙げている
- **手間**: 入れるのは1行。ただし **作るのは遅い**（数分、3Dの点検まで含めると15〜20分かかる例がある）
- **気をつけること**: グラフ（軸・系列）は作れない。人物や正確な地図も対象外。3D の表示は試験中

## 生成AI向けの詳細

> ここから下を、そのまま AI に渡してください。

### あなた（AI）への依頼

利用者が「〇〇の仕組みを図にして」「〇〇がどう動くか見せて」と頼み、それが **機械・装置・道具・システムの構造** なら、Anatomy スキルを使って立体の説明図を作ってください。
グラフ・人物・正確な地図なら、このスキルは使わずに、そう伝えて別の方法（05 の図のスキルなど）を提案してください。

### 1. 前提を確かめる

```bash
node -v
```

- `v20.10` 以上が要る。入れるのに skills CLI（`npx skills`）を使うなら `v22.20` 以上
- Chrome か Chromium が入っているか。標準の場所に無ければ、環境変数 `CHROME_PATH` でその実行ファイルを指せる

### 2. 入れる（どれか1つ）

README に載っている形をそのまま使う。

```bash
npx skills add wheresryan22/anatomy -g -a claude-code
```

```bash
npx skills add wheresryan22/anatomy -g -a codex
```

```bash
git clone https://github.com/wheresryan22/anatomy.git ~/.claude/skills/anatomy
```

`npm install` は要らない（Node.js に最初から入っている部品だけを使う、と README にある）。

### 3. 使う

- Claude Code: `/anatomy explain how a token bucket rate limiter works, interactive`（README の例。日本語で頼んでもよいが、結果のラベルの言語を指定する）
- Codex: `$anatomy`
- 「立体のイラストにして」「対話的な説明図にして」のような普通の頼み方でも呼ばれることがある（README の記載）

出力は次のどれか（README の記載）:

- 1枚の HTML を書き出す Node のスクリプト
- スタイルを埋め込んだ `.svg` 1枚
- React / Next.js の部品

### 4. 進め方

1. 利用者に **何の仕組みか、どこまで細かく分けるか（部品の数）、動かしたい部分** を聞く
2. まず静止した図で、部品の名前と配置が合っているかを見てもらう
3. 合ってから、動き・分解・3D の順で足す（3D は試験中で、時間もかかる）
4. 時間がかかることを先に伝える（数分〜20分）

### やってはいけないこと

- `publish.mjs --submit`（作品を共有の場へ PR として送る）を、利用者の明示の許可なく実行しない。社内の仕組みを描いた図を外へ出すことになる
- 社外秘の構成図を、利用者の確認なく作例として残さない

### うまくいかないとき

| 症状 | 見るところ |
|---|---|
| 点検のスクリプトが Chrome を見つけられない | `CHROME_PATH` に Chrome の実行ファイルを指定する |
| 炎・水・煙などの効果が出ない | WebGL が使えない環境。SVG の部分だけは表示される（README の記載） |
| Codex で点検が失敗する | 箱（サンドボックス）が Chrome と手元のポートを許しているか（README の記載） |
